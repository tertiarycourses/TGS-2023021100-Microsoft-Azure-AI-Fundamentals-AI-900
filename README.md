## About the course

The course connects AI workload selection to practical Azure implementation evidence. Learners classify AI problems, interpret machine-learning metrics, explore Microsoft Foundry and Azure AI capabilities, deploy or review planned workflows, identify operational issues, and maintain clean interoperable data for search and knowledge-mining solutions.

## Learning outcomes

By the end of the course, learners should be able to:

- implement AI applications with Microsoft Azure services;
- deploy AI workflows on Azure;
- identify and report anomaly, application and collected-data issues; and
- maintain data interoperability and perform data cleaning with Azure knowledge mining.

## Topics covered

- AI workloads, Responsible AI and Microsoft Foundry
- Machine learning fundamentals, regression, classification, clustering and metrics
- Azure Machine Learning designer, jobs and AutoML lifecycle
- Computer vision, image analysis, OCR and Document Intelligence
- Language analysis, PII, speech, translation and conversational AI
- Generative AI, grounding, agent controls and content safety
- Anomaly evidence, governance, data quality and human review
- Azure AI Search, indexes, indexers and knowledge mining
